# Planet Info Panel

## Підключення

1. Відкрийте `Assets/Scenes/MainARScene.unity`, дочекайтеся компіляції, вийдіть із Play Mode.
2. Виконайте **Solar System > Setup Planet Info Panel**. Скрипт імпортує стандартні TMP Essential Resources, якщо їх немає, створить `Assets/UI/PlanetInfo/PlanetInfoPanel.prefab`, статичний TMP-шрифт з українськими символами і круглий placeholder. Додасть екземпляр prefab та EventSystem з InputSystemUIInputModule, якщо їх ще немає.
3. Збережіть сцену. Повторний запуск setup не створює дублікати та не перезаписує налаштований prefab. Сценові посилання інших компонентів не змінюються.
4. Посилання панелі заповнюються автоматично. `App Controller` можна залишити порожнім: панель знайде наявний AppController при ввімкненні. За наявності кількох контролерів призначте потрібний явно.

Якщо Unity ще завершує імпорт TMP і setup не закінчився, дочекайтеся імпорту та повторіть команду. Не додавайте порожній компонент PlanetInfoPanel вручну: використовуйте згенерований prefab із заповненими UI-посиланнями.

## Зображення

У `Assets/Data/Planets/*Data.asset` з'явилося сумісне поле **Image** (`Sprite`), за замовчуванням порожнє. Для власного зображення з перевіреною ліцензією виберіть Texture Type = Sprite (2D and UI), Sprite Mode = Single і перетягніть Sprite в Image відповідної планети. Бажане квадратне зображення з планетою по центру; маска обрізає його до кола.

Без Sprite панель показує кольорове коло, назву планети та «ЗОБРАЖЕННЯ ВІДСУТНЄ». Колір залежить від PlanetId, тому при перемиканні планети placeholder теж змінюється. Наявні текстури в Assets/Textures не перепризначаються: вони використовуються моделями та не обов'язково є готовими портретами. Нових зовнішніх зображень не завантажено.

## Контракт

- AppController зберігає `CurrentPlanetInfo` та публікує `PlanetInfoChanged`. Значення null приховує картку.
- Успішний вибір планети (включно з екскурсією) публікує вступ з наявних числових і текстових полів PlanetData. Екскурсія потім публікує факт відповідно до наявної поведінки контролера.
- ShowFact / ShowHistory використовують передану командою планету або поточну вибрану. Явна планета в такій команді оновлює картку без зміни вибору/руху екскурсовода, як і попередня голосова логіка.
- Overview / Cancel приховують картку. Help, питання, Repeat і Stop не замінюють її вміст.
- UI не підписується на NarrationRequested, не надсилає команд і не дублює вибір планети. Контракт IAppController, озвучення, субтитри та AR-компоненти не змінено.
- CanvasGroup анімує прозорість за unscaled time. Прихована картка не перехоплює UI-введення. Safe area перераховується після повороту екрана. ScrollRect підтримує drag і колесо миші.

## Перевірка

У Play Mode через наявний Debug UI:

1. **Mars**: назва «Марс», секція «ПРО ПЛАНЕТУ», структуровані характеристики, Sprite або placeholder.
2. **Fact**: «ЦІКАВИЙ ФАКТ», текст interestingFact з MarsData.
3. **History**: «ІСТОРІЯ ДОСЛІДЖЕННЯ», текст discoveryHistory; довгий текст прокручується.
4. **Earth**: назва «Земля», вступ і зображення/колір placeholder змінюються; прокручування скидається вгору.
5. **Overview** приховує картку; **Mars** знову відкриває; **Cancel** приховує.
6. **Help**, **Repeat**, **Stop** та питання не змінюють картку; голосовий канал продовжує отримувати попередні події.
7. Тимчасово очистіть Image у PlanetData: показується placeholder. Тимчасово видаліть запис каталогу на AppController: вибір наявного об'єкта планети показує українську назву й повідомлення про відсутність даних. Відновіть Inspector після перевірки.
8. Перевірте portrait/landscape і safe area на Android; один палець прокручує текст, AR-сцена лишається видимою. Перед AR-взаємодією спочатку розмістіть систему як зазвичай. Наявний ARPlacementController самостійно читає дотики, його поведінка не змінена.

Debug UI намальований через IMGUI і може перекривати частину картки на вузькому екрані: після команди натисніть **Hide Test UI** для огляду картки.

Додаткова перевірка без Play Mode: **Solar System > Validate Planet Info Commands**. Вона використовує реальний AppController на тимчасових ізольованих GameObjects, перевіряє Mars/Fact/History/Earth, приховування/повторне відкриття, незалежність від озвучення та відсутні дані. Поточна сцена не змінюється.

## Компактна версія

Панель має максимальний розмір 500 × 320 замість 760 × 530, темніший фон і відступ від верхніх тестових кнопок. Службові написи Database/Footer приховані. Вступ містить тільки тип, діаметр і рік; факти та історії збережені повністю й прокручуються.

Кожне оновлення картки перезапускає анімацію появи тривалістю 0,28 с (прозорість, масштаб 94–100%, невеликий зсув). Це працює також для повторного вибору тієї самої планети і команд Fact/History.

Після виходу з Play Mode і компіляції `PlanetPortraitSetup` автоматично створює круглі освітлені портрети всіх восьми планет з наявних Assets/Textures/*.png, записує їх у Assets/UI/PlanetInfo/Portraits і заповнює порожні PlanetData.image. Власні призначені Sprite не замінюються. Оригінальні текстури та їх імпортери не змінюються. Повторний ручний запуск за потреби: Solar System > Refresh Planet Portraits. Існуючий prefab оновлюється зі збереженням object IDs; повторний Setup не потрібний.

Після цих змін перевірена C#-компіляція з бібліотеками Unity. Новий вигляд і генерацію портретів слід перевірити в Editor після виходу з Play Mode.
